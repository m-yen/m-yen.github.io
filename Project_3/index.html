Deliverable 2: Homography Computation (DLT)

The `computeH(im1_pts, im2_pts)` function was implemented using the Direct Linear Transformation (DLT) algorithm. This function takes at least four pairs of corresponding points to solve for the $3 \times 3$ homography matrix $\mathbf{H}$ that maps points from $im1$ to $im2$.

Deliverable 3: Image Warping (Nearest Neighbor vs. Bilinear)

The functions `warpImageNearestNeighbor(im, H)` and `warpImageBilinear(im, H)` were implemented using inverse warping to perform image rectification. Inverse warping ensures that every pixel in the destination image is sampled from the source, avoiding holes.
