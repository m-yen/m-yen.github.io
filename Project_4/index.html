Part 1: Fit a Neural Field to a 2D Image

Model Architecture Report

I used 4 fully connected layers interlaced with ReLU activation functions. I ended things with a 
sigmoid layer to constrain the output to values in the range (0, 1). Each layer was 256 neurons wide
and I used a learning rate of 1e-2. I used MSE loss and ran 14 epochs of batch sizes of 10,000, 
which came out to slightly over 1,000 iterations.

I tested on sizes width sizes 256 and 32 and positional encoding sizes of 2 and 10.

Part 2: Fit a Neural Radiance Field (NeRF)

Implementation Description

Camera to World - This was implemented using homogenous coordinates. I added a 4th dimensions to the 
            camera coordinate vectors and left multipled by the c2w matrix which was given. 
            I then removed the added 4th dimension to retreive the world coordinates. 

    Pixel to Camera - I calculated the conversion from image coordinates to camera coordinates by deriving
            the formula from the matrix multiplication. Rewritten, we know:
                x = (z / f_x) * (u - o_x)
                y = (z / f_y) * (v - o_y)
                z > 0

            We choose to arbitrarily set Z to depth 1. This is acceptable since we sample 
            along the ray in the z direcation later and integrate it out, so we can choose
            the simplest Z for the calculation.

            The o_x and o_y are set to half the width and half the height

            f_x and f_y is just set to the focal length of the camera.

    Pixel to Ray - Once the world coordinates can be recovered by converting from pixel to camera
                    then to world, we want to turn the world coordinates into a ray so we can
                    easily calculate depths for sampling.

                    This is as simple as applying the formula given in the project spec.

                    R0 is set to the translation component of the c2w matrix and Rd is set to
                    a normalized difference of each world coordinate (x, y, z) and R0

    
    Sampling Rays - We next want to sample rays. This is simply done by converting all the pixels 
                accross all pictures into rays, then simply randomly sampling. 


    Sampling Along Rays - For inference, we sample 64 points along the ray using np.linspace. For
                            training, we want to have points, and do this by adding small 
                            pertibations. This was calculated by setting the distance long the ray
                            t = t + (np.random(t.shape) * t_width)

    Dataloader - We need to make a dataloader for training with Torch, so we create a seperate 
                    dataset class for the NeRF. We conduct all the above except sampling to retreive
                    the rays for all the pixels across all the images. We then set the len of the 
                    dataset to be the number of rays and set the getItem function to be index the 
                    desired rays and corresponding pixels from the data.

    MLP Construction - I created a NN with 8 fully connected layers interlaced with ReLU activation
                        functions. I also added the original input back into the 4th layer to 
                        ensure information is not forgotten. From there I had two outputs, one for 
                        the density parameter, and another 2 fully connected components for the 
                        rgb output. We don't introduce Rd until after the 8 connected layers. I
                        also used positional encoding of size 10 and 4 for the coordinates and rays.


    Volumetric Rendering - This process is done by summing the colors along a ray. This is done in a
                            forward to back fashion by multiplying every point on the ray the amount
                            light that permeated through the previous layers. This is found by multiplying
                            the color by 1 - torch.exp(-sigmas * step_size) and torch.exp(-torch.cumsum(offset, dim=1)).
