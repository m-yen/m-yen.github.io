Project 1: Image Alignment

A demonstration of naive and pyramid-based alignment methods.

Discussion Notes

Naive Alignment

Write here about how the naive method works, the search window size, when it performs well (e.g., small images like cathedral, church), and when it fails (e.g., emir with large displacements).

Pyramid Alignment

Discuss the pyramid approach, how it aligns from low → high resolution, and why it works better on large images. Mention improvements you observed on images like emir and harvesters.

Metrics (L2 vs NCC)

Compare L2 distance and Normalized Cross-Correlation (NCC). L2 is simple but brightness-sensitive, while NCC is more robust to intensity differences. Note which worked better in your results.

Edge-based Alignment

Add notes about using edges (like Sobel filters) for alignment. When did this help reduce artifacts? When did it hurt performance?

Final Thoughts

Wrap up with the method that gave you the best overall performance (likely pyramid + NCC). Mention lessons learned and possible future improvements (cropping borders, better edge detection, histogram equalization).
