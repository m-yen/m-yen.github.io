Project 1: Prokudin-Gorskii Photo Colorization

Project Overview

Sergei Mikhailovich Prokudin-Gorskii (1863–1944) was a pioneering photographer who foresaw the potential of color photography over a century ago. Starting in 1907, he traveled across the Russian Empire under special permission from the Tsar, capturing thousands of color photographs of people, buildings, landscapes, and infrastructure. The goal of this project is to take the digitized Prokudin-Gorskii glass plates and automatically produce full-color images using image processing techniques. This involves:

  • Extracting the three color channels (B, G, R) from each glass plate.
  • Aligning the channels to account for small displacements between exposures.
  • Stacking the channels to create a single RGB image with minimal visual artifacts.

Methodology

1. Brute-Force Alignment

This method is implemented in the `GlassPlate` class and works by systematically checking every possible displacement within a defined search window.

  • `trim_colors()`: This function first divides the large glass plate image into three equal-height channels: Blue (B), Green (G), and Red (R).
  • `find_best_align()`: This function is the core of the brute-force alignment. It compares a reference channel (usually Blue) to a target channel (Green or Red) at various shifts. It iterates through all possible horizontal (`dx`) and vertical (`dy`) shifts within a specified `radius`.
  • Metric: For each shift, it calculates a metric to determine how well the images match. Your code uses Normalized Cross-Correlation (NCC), which is a robust metric that's insensitive to changes in brightness and contrast. The best alignment is the one that yields the highest correlation value.
  • `align_two_colors()`: This function calls `find_best_align()` to get the best shifts. It then applies these shifts to the target channel using `np.roll()`, which circularly shifts the image data.
  • `align_colors()`: This method orchestrates the alignment process, calling `align_two_colors()` for both the green and red channels against the blue channel, and then stacks the aligned channels together to create the final color image.

2. Pyramid-Based Alignment

This is an optimization of the brute-force method, implemented in the `GlassPlatePyramid` class, designed to handle large, high-resolution images more efficiently.

  • `build_gaussian_pyramid()`: This function creates a Gaussian pyramid, a sequence of downscaled images. It repeatedly blurs and subsamples the image, creating smaller and smaller versions. This is crucial for performance.
  • `align_from_pyramids()`: This is the key function for this method. Instead of searching the full-resolution image, it starts by finding a rough alignment on the smallest image in the pyramid.
  • Hierarchical Search: Once an initial alignment is found on a small image, the displacement values are scaled up and used as the new search center for the next, larger level of the pyramid. This process repeats until the full-resolution image is reached.
  • Efficiency: This hierarchical search significantly reduces the search space at each level. Instead of searching `N x N` pixels at full resolution, you search a small window around a known good estimate. This makes the process much faster, especially for very large images.
